# Sustainability Game for the City of Davis

This repository contains the source code for a mobile game designed to promote sustainability and environmental awareness in the City of Davis. Built with Flutter, this game aims to educate and engage players in interactive challenges and activities around sustainability.

## Features

- Interactive gameplay focused on environmental themes
- Educational content about sustainability practices in Davis
- Engaging challenges and activities for players
- Modern Flutter-based codebase, supporting cross-platform (iOS & Android)

## Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install)
- A working installation of [Dart](https://dart.dev/get-dart)
- Android Studio or Xcode for platform-specific builds

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/starobserver-creator/game2.git
   cd game2
   ```

2. Install dependencies:
   ```sh
   flutter pub get
   ```

3. Run the app:
   ```sh
   flutter run -d chrome
   ```
   Targets web for all devices, unknown build stability for other platforms 

## Project Structure

- `lib/` - Main Dart codebase
- `assets/` - Images, sounds, and other assets
- `test/` - Automated tests
